# Contributing to the OrgSets Community Hub

Thank you for helping improve [OrgSets](https://orgsets.com) and the [RadTome](https://radtome.com) software ecosystem!

This repository is dedicated to public issue tracking, feature discussions, architectural documentation, and community resources.

---

## Ways to Contribute

### 1. Reporting Bugs
- Search existing [Issues](https://github.com/RadTome/OrgSets/issues) to ensure your bug has not already been reported.
- If not reported, submit a new report using the [Bug Report Template](https://github.com/RadTome/OrgSets/issues/new?template=bug_report.yml).
- Include precise reproduction steps, browser/OS version, and expected vs actual outcomes.

### 2. Suggesting Features
- We welcome innovative ideas for improving hierarchical organizations, ledger auditing, communication tools, and governance.
- Use our [Feature Request Template](https://github.com/RadTome/OrgSets/issues/new?template=feature_request.yml).
- Describe the administrative pain point you're trying to solve and how it impacts your organization.

### 3. Community Discussions
- Join our [GitHub Discussions](https://github.com/RadTome/OrgSets/discussions).
- Categories:
  - **General:** Open discussions on community leadership, chapter administration, and workflow tips.
  - **Ideas:** Brainstorming concepts before formalizing into feature requests.
  - **Q&A:** Help with setting up parent/child nodes, Stripe splits, or custom role configurations.
  - **Show and Tell:** Share how your council, league, or association uses OrgSets!

### 4. Improving Public Documentation
- The `/docs` folder hosts the GitHub Pages community site ([https://radtome.github.io/OrgSets/](https://radtome.github.io/OrgSets/)).
- Contributions to documentation clarity, SEO enhancement, spelling, and responsiveness are welcome via Pull Request!

---

## Pull Request Guidelines

1. Fork the repository and create a feature branch (`git checkout -b doc/improve-feature-matrix`).
2. Make concise, clean edits adhering to the Bauhaus/Brutalist design language.
3. Verify all external links to [orgsets.com](https://orgsets.com) and [radtome.com](https://radtome.com) are valid.
4. Submit your Pull Request with a clear summary of changes.

---

## Community Etiquette

Please be polite, constructive, and respectful. All participants are expected to adhere to our [Code of Conduct](./CODE_OF_CONDUCT.md).
