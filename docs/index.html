FREQUENTLY ASKED QUESTIONS

Key questions regarding OrgSets multi-tenant capabilities, financial ledgers, and community collaboration.

OrgSets is an all-in-one hierarchical multi-tenant platform created by RadTome. It is built specifically for communities with real structural depth: youth athletic leagues, scout councils, fraternal organizations, alumni associations, and professional networks who need structured authority, automated financial splitting, and emergency broadcast dispatch.

RadTome is the parent software project organization and engineering factory behind OrgSets. RadTome develops high-utility developer platforms, Chrome Web Store extensions like QuickSnipe, edge registries like MCP Codex, and local-first utilities like PrettyPrint. RadTome engineers OrgSets with high-performance Java 21 GraalVM Native compilation and modern React 19 architecture.

OrgSets integrates with Stripe Connect Custom and Express accounts. When a member pays registration fees or annual dues at a local chapter level, OrgSets automatically calculates percentage-based allocations up the parent tree. In a single transaction, the National Council receives its levy, the Regional League takes its tournament cut, and the Local Chapter retains the remainder—complete with an immutable audit trail.
